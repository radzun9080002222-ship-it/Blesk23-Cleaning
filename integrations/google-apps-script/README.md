# Google Forms → amoCRM

Исходник привязанной к таблице `Blesk23 (Ответы)` интеграции.

## Что делает

- запускается по новой строке Google Forms;
- разбирает блок `Атрибуция` из сообщения;
- заполняет технические колонки F:Z;
- ищет контакт в amoCRM по нормализованному телефону;
- если у контакта есть заявка в «Неразобранном», принимает её и дополняет вместо создания дубля;
- иначе дополняет последнюю открытую сделку ранней стадии за последние 30 дней;
- если контакт из «Неразобранного» ещё недоступен обычному поиску amoCRM, отправляет заявку через `POST /api/v4/leads/complex` со штатным контролем дублей по телефону;
- после первой заявки через `POST /api/v4/leads/complex` amoCRM автоматически создаёт источник интеграции и показывает его в настройках контроля дублей;
- создаёт новый контакт и новую сделку только при отсутствии подходящей активной сделки;
- не объединяет новую заявку с назначенной, выполненной или закрытой уборкой;
- назначает Ферузу ответственной за принятую, дополненную или новую сделку;
- заполняет UTM, `yclid`, ClientID Метрики, посадочные страницы и услугу;
- записывает клики по телефону как технические строки без создания сделки;
- для заявки из внутреннего `/calc` подставляет атрибуцию, только если за 15 минут найден ровно один незанятый `phone_click`;
- помечает такую атрибуцию как эвристическую, а при нуле или нескольких кликах не приписывает сделке чужие UTM;
- добавляет расчёт и всю атрибуцию в примечание существующей сделки без потери старых данных;
- ставит задачу на первый контакт со SLA 5 минут в рабочее время 08:00–23:00, только если у сделки ещё нет открытой задачи;
- записывает `amo_lead_id`, статус синхронизации и ошибку обратно в таблицу.

## Секрет

Токен не хранится в репозитории. В свойствах проекта Apps Script должен быть ключ:

```text
AMO_LONG_LIVED_TOKEN=<токен приватной интеграции amoCRM>
```

После установки токена один раз запускается `setupIntegration()`. Функция проверяет соединение и создаёт установленный триггер `handleFormSubmit`.

Во внешней интеграции amoCRM должна быть включена опция **Контроль дублей**. Источник внешней интеграции нельзя создать через API без JS-виджета: amoCRM добавит его автоматически после первой заявки через `POST /api/v4/leads/complex`. После контролируемого теста для этого источника в воронке настраиваются: сравнение по телефону, поиск в «Неразобранном» и ранних активных стадиях, обновление самой новой сделки и дополнение данными входящей заявки.

Для карточки внешней интеграции amoCRM подготовлен файл `assets/amo-integration-logo.png` точного размера 400×272 px.

Существующие строки таблицы должны иметь статус `historical_existing`, чтобы интеграция не создала по ним повторные сделки. Повтор конкретной строки выполняется вручную через `retryRow(<номер>)`.
